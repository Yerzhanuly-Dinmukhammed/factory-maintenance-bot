# Бот для обслуживания оборудования

[English README](../README.md) · [Безопасность](../SECURITY.md)

Telegram-бот связывает заявки на ремонт, планово-предупредительный ремонт (ППР),
учёт смен и отчётность. Интерфейс рассчитан на операторов, слесарей,
бригадиров/технологов и администраторов.

## Что реализовано в исходнике

- Заявки: оборудование, срочность, фото, принятие слесарем, ETA, выполнение и оценка.
- ППР: расписание, напоминания, перенос с причиной и проверка бригадиром по цехам.
- Явка: дневная и суточная смены.
- Рейтинг: очки, таблица лидеров, утренние сообщения и недельные итоги.
- Отчёты: Google Sheets, Excel через openpyxl и графики Matplotlib.
- Администрирование пользователей, имущества и расписания.

## Что находится в репозитории

Это очищенная копия исходника, а не подключённый рабочий бот.
Реальные ключи, сотрудники, заявки, ППР, явка, справочники оборудования,
логи, бэкапы и личные документы не включены. Производственная история Git
не переносилась.

Имя основного файла для этой копии — `bot.py`. Рабочие исходники при подготовке
репозитория не изменялись и не запускались.

## Как проверять

Вначале можно выполнить только безопасные статические проверки:

```bash
python -m unittest discover -s tests -v
```

Они читают код как текст и AST, не импортируют бот, не отправляют сообщения
и не обращаются к Google. Полный функциональный тест опубликованной копии
не проводился.

Для самостоятельного запуска нужны отдельный тестовый бот, новая пустая
Google-таблица и собственные тестовые настройки. Переменные окружения и порядок
установки описаны в [основном README](../README.md#safe-local-setup).
Файл `.env.example` — только шаблон; автоматической загрузки `.env` в коде нет.

Цеха, оборудование и ППР потребуется добавить заново через административные меню.
Не используйте рабочие данные завода для демонстрации проекта.

## Ограничения

QR-ссылки регистрации не являются секретными или одноразовыми. В текущей логике
ссылка бригадира позволяет оператору сменить роль; перед внедрением нужно отдельно
проверить политику регистрации и доступ ко всем действиям. Повторы запросов к Google
не гарантируют отсутствие дублей. Подробнее — в [SECURITY.md](../SECURITY.md).
